# API Contracts

This project is a static documentation website generated by Docusaurus.

There are **no external APIs** developed for or consumed by this project in the traditional sense (e.g., REST, GraphQL).

The only "contract" is the structure of the Markdown files and the Docusaurus configuration, which dictates the content and navigation of the site. This is documented in the `data-model.md` file.

The conceptual chatbot described in the specification is for documentation purposes only and does not involve an API integration at this stage.
